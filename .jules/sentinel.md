## 2024-08-28 - SSRF and Protocol Bypass in URL Sanitizer
**Vulnerability:** The `isValidUrl` and `sanitizeUrl` functions used `.includes('evzone.com')` for hostname validation, allowing SSRF bypasses via malicious domains (e.g., `evzone.com.attacker.com`). They also failed to enforce strict protocol allowlists before evaluating hostnames, allowing bypasses using `javascript:` protocols or unstripped whitespace.
**Learning:** Standard string methods like `.includes()` are insufficient for security boundaries. Hostnames must be checked with strict equality (`===`) for the root domain and strict suffix matching (`.endsWith('.domain.com')`) for subdomains. URLs must always have whitespace stripped and protocols explicitly verified against an allowlist before further processing.
**Prevention:** Always validate protocols strictly before evaluating URL properties. When validating domains against SSRF/Open Redirects, use strict equality and strict suffix matching, never `.includes()`. Strip whitespace to prevent injection attacks that break URL parsing logic.
