## 2026-09-14 - [CRITICAL] URL Validation SSRF & Open Redirect Bypass via .includes()
**Vulnerability:** The `isValidUrl` and `sanitizeUrl` functions used `.includes('evzone')` for hostname validation, allowing bypasses via subdomains like `evzone.com.attacker.com` or `my-evzone.com`. Additionally, naive `new URL()` parsing without whitespace stripping or strict protocol allowlists permitted newline/tab injections and protocol-relative bypasses.
**Learning:** Using `.includes()` on URL hostnames is a fundamentally insecure pattern for SSRF and Open Redirect prevention in this codebase. Malicious domains can trivially contain the target string as a substring.
**Prevention:** Always use strict equality (`=== 'domain.com'`) combined with strict suffix matching (`.endsWith('.domain.com')`) for hostname validation. Always strip whitespace (`/[\n\r\t]/g`) before `new URL()` parsing, and enforce strict, explicit protocol allowlists (e.g., `['http:', 'https:']`) before evaluating hostnames.
