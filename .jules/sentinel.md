## 2026-10-07 - Fix URL validation and sanitization XSS vulnerabilities
**Vulnerability:** URL validation and sanitization in `src/sanitizers/url.ts` was vulnerable to XSS and Open Redirect. It failed to sanitize whitespace characters, allowing `javascript://` URLs with newline injection to bypass the `URL` constructor logic. Furthermore, it relied on a weak `.includes('evzone.com')` check, making it susceptible to hostname spoofing (e.g., `https://evzone.com.attacker.com`), and lacked strict protocol allowlists in `sanitizeUrl` and `extractHostname`.
**Learning:** The `URL` constructor parsing `javascript:` URLs does not throw an error, and `.includes` is insufficient for domain validation. Whitespace removal before URL parsing is necessary to prevent bypasses.
**Prevention:** Always strip whitespace characters before passing URLs to the `URL` constructor. Enforce exact hostname matching or proper subdomain matching (`endsWith('.evzone.com')`) rather than partial string matching. Enforce an explicit protocol allowlist (e.g., `['http:', 'https:']`) before performing any URL operations.
