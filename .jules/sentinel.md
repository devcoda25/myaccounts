## 2026-07-08 - [CRITICAL] Open Redirect / SSRF Bypass via Insecure Domain Validation
**Vulnerability:** The `isValidUrl` function used `.includes('evzone.com')` for domain validation and naive parsing via `new URL(url)`, allowing bypasses via malicious domains like `evzone.com.attacker.com` or whitespace injection (e.g., `javascript://%0aalert(1)//evzone.com`).
**Learning:** Using `.includes()` for domain matching is extremely vulnerable to suffix/prefix additions. The JS `URL` constructor can also parse URLs with injected whitespace or tabs, leading to bypasses if the protocol and hostname are not strictly validated. Safe relative paths also need explicit handling to avoid breaking client-side routing when parsing URLs.
**Prevention:** Always use strict regular expressions with anchors (`^` and `$`) for domain matching, ensuring full subdomain hierarchies are safely allowed. Strip whitespace characters before passing input to the `URL` constructor to prevent protocol injection.
