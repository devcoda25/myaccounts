## 2024-08-01 - [CRITICAL] Insecure URL Validation (SSRF / Open Redirect bypass)
**Vulnerability:** The `isValidUrl` and `sanitizeUrl` functions used `.includes('evzone.com')` to validate domains, allowing an attacker to bypass validation using domains like `evzone.com.attacker.com` or `attacker.com/evzone.com`. Additionally, it did not properly handle relative paths securely, strip whitespace, or strictly enforce protocols before evaluating hostnames which could lead to bypasses.
**Learning:** Using `.includes()` for domain validation is insecure. The `URL` constructor parsing needs to be used safely, protecting against whitespace injection and malicious protocols (like `javascript:`). Hostname checks must use strict equality or `.endsWith('.evzone.com')`.
**Prevention:** Always use strict suffix matching (`hostname === 'domain.com' || hostname.endsWith('.domain.com')`) and properly strip whitespace (`.replace(/[\n\r\t]/g, '').trim()`) before parsing URLs. Explicitly handle safe relative paths if required, and always enforce strict protocol allowlists.
