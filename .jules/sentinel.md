## 2026-09-14 - Fix URL validation bypasses (SSRF, Open Redirect, XSS)
**Vulnerability:** URL validation (`isValidUrl`) used `.includes('evzone.com')`, which allowed SSRF and Open Redirect bypasses via malicious domains (e.g., `attacker-evzone.com`). Additionally, `sanitizeUrl` allowed XSS payloads (`javascript:`) because it did not enforce a strict protocol allowlist, and `new URL()` is vulnerable to whitespace injection.
**Learning:** The Javascript `URL` constructor parses whitespace in a way that allows payloads like `javascript:alert(1)//evzone.com`. Furthermore, suffix matching for domains must use strict equality and `.endsWith('.domain.com')` to be secure, as partial matching is universally exploitable.
**Prevention:** Always enforce a strict protocol allowlist (`['http:', 'https:', 'mailto:', 'tel:']`), pre-strip whitespace (`url.replace(/[\n\r\t]/g, '').trim()`), and use strict domain matching (`=== 'domain.com' || .endsWith('.domain.com')`) for validation.
