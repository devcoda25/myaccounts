## 2024-05-18 - [HIGH] Fix Open Redirect and Path Traversal
**Vulnerability:** Found multiple Open Redirect vulnerabilities via weak URL validation (e.g., using `new URL().hostname.includes()` which can be bypassed via `domain.com.attacker.com` or `javascript:` protocol with newlines) and unverified dynamic URL assignment to `window.location.href`. Also found a Path Traversal vulnerability due to using `!segment.includes('/')` for path validation, which can be bypassed using backslashes.
**Learning:** `new URL()` in JS does not throw on valid formats that may bypass naive substring checks. Dynamic parameters supplied to `window.location.href` must be strictly validated. Validating dynamic path segments with simple `.includes('/')` is insufficient since backslashes can bypass it.
**Prevention:** Always strip whitespaces before parsing URLs, use exact or strict regex matching for trusted hosts in URL validators, and wrap all `window.location.href` assignments in strict validation checks. Use allowlist character regexes (like `/^[a-zA-Z0-9-_]+$/`) instead of simple substring matching to validate URL segments and prevent path traversal.
