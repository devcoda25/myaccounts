## 2024-05-24 - URL Validation Bypass via Substring Matching
**Vulnerability:** The URL sanitizer used `.includes()` for hostname validation (`parsed.hostname.includes('evzone.com')`), which allowed domains like `evzone.com.evil.com` to bypass checks. The `javascript:` protocol was also poorly filtered, allowing `\n` or `\t` characters to bypass protocol checks in certain cases.
**Learning:** `.includes()` is dangerous for hostname validation due to the hierarchical structure of DNS (where attacker-controlled domains can contain the target substring). Furthermore, `URL` objects parse protocols loosely in some browsers/environments unless strictly allowlisted and cleaned.
**Prevention:** Always use exact matching (`===`) or strict suffix matching (`.endsWith()`) for hostnames. Ensure the URL string is stripped of whitespace characters (`url.replace(/[\n\r\t]/g, '').trim()`) and enforce an explicit protocol allowlist (e.g., `['http:', 'https:']`) before further validation.
