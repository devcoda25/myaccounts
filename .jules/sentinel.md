## 2026-10-23 - [CRITICAL] Fix URL Validation SSRF/Open Redirect Bypass
**Vulnerability:** Weak URL validation in `isValidUrl` and `sanitizeUrl` used loosely matched `.includes('evzone.com')` for hostname checks. This allowed bypasses via subdomains like `evzone.com.attacker.com` or directories like `attacker.com/evzone.com`. It also lacked protocol allowlisting prior to hostname checks (allowing `javascript:`), and didn't strip whitespace to prevent injection bypasses.
**Learning:** Never use `.includes()` for domain matching, as it easily allows bypasses by placing the target string anywhere in the hostname or path. `new URL()` also parses malicious protocols like `javascript:` without errors, resulting in empty or unexpected hostnames.
**Prevention:** Always use strict exact matching (`===`) or strict suffix matching (`.endsWith()` with a dot) for hostnames. Ensure a strict protocol allowlist (`['http:', 'https:']`) is enforced before any hostname validation. Always strip whitespace (`[\n\r\t]`) prior to parsing.
