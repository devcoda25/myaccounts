## 2024-05-18 - [Fix Open Redirect / SSRF Domain Validation bypass]
**Vulnerability:** The `isValidUrl` function used `.includes('evzone.com')` to validate domains, which allows attackers to bypass validation using domains like `evzone.com.attacker.com`. Additionally, `new URL` parsing without proper whitespace sanitization or protocol constraints could allow malicious inputs to bypass hostname checks.
**Learning:** Naive string matching (`.includes()`) for domain validation is insufficient and prone to subverting via subdomains. Using `new URL()` can also exhibit unexpected behavior with non-standard protocols if not strictly validated against an allowlist.
**Prevention:** Always use strict domain regexes (`/^([a-z0-9-]+\.)*(evzone\.com|evzone\.app|evzonemarketplace\.com)$/i`) or exact matching (`===`) for domain validation. Clean inputs (remove whitespace) and strictly enforce allowed protocols (http, https) before parsing or validating URLs. Allow safe relative paths explicitly if needed.
